# SA Cook Assistant Windows Preview 5.42

- SPACE có luồng thu riêng, chốt trong khoảng 80 ms, gửi một file WAV 16 kHz duy nhất và không còn phải chờ nhiều đoạn AUTO.
- SPACE ưu tiên mô hình nhận diện độ trễ thấp; tự chuyển sang mô hình tương thích khi tài khoản chưa hỗ trợ.
- Không chạy Web Search trong lần trả lời SPACE đầu tiên; chỉ dùng khi bấm thử lại để giảm thời gian chờ.
- Thêm nút **Update** để kiểm tra, tải, xác minh SHA-256 và cài bản Windows mới trực tiếp từ GitHub Releases.
- Cập nhật chỉ trong đúng thư mục portable, giữ bản sao dự phòng và xác nhận bản mới mở thành công; nếu thay thế lỗi, trình cập nhật phục hồi và mở lại bản cũ.
- Không cần tải và giải nén thủ công từ những lần cập nhật tiếp theo.

Lưu ý: lần đầu chuyển từ 5.41 lên 5.42 vẫn cần cài bản 5.42 thủ công vì bản 5.41 chưa có trình cập nhật tích hợp.
